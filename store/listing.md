# Chrome ウェブストアの掲載情報（2.0.0）

デベロッパー ダッシュボードに貼り付ける文章です。

## 概要

パッケージ（manifest の description）から自動で入ります。2.0.0 の zip には、以前のバージョンと同じ次の文が入っています（変えない）。

```
ニコニコ生放送の視聴中の番組を録画し、後で見返すことができるツールです。
```

## 説明

説明は、今のストアの説明のまま変えない（貼り替えない）。以下は、書き換える場合の案です。

```
ニコニコ生放送で見ている番組を、ブラウザの中でそのまま録画する拡張機能です。録画は数秒ごとに自動で保存され、設定した容量を超えると古いものから順に削除されるので、見た番組の「動画の履歴」が残っていきます。

■ 主な機能
・録画バー
　プレイヤーの下に録画バーが出て、録画の状態と時間、録画している画質がひと目で分かります。番組を開くと自動で録画を始めます（オートスタート）。
・3種類の録画
　「コメントなし」（映像と音声をそのまま）、「コメントあり」（流れるコメントを重ねて）、「画面録画」（ゲームやギフトの演出も含めて、プレイヤーの画面をそのまま）を同時に録画できます。録画する種類は、タブごとに切り替えられます。
・プレイバック
　録画を止めずに、少し前の場面を別ウィンドウで見返せます。生放送を見ながら「さっきのシーン」をすぐ確認できます。
・録画一覧
　録った番組を番組ごとに並べて、タイムラインから再生できます。番組名・配信者での検索、種類での絞り込み、まとめての削除もできます。
・保存
　録画は画質を落とさずに mp4 で保存できます（番組まるごと・ファイルごと）。見ている場面のスクリーンショット（png）や、前後30秒ずつ（計1分）の動画、録画バーからは直前1分の動画も保存できます。
・配信の画質が変わった時の録り方
　画質が変わった所で分けて録るか、決めた大きさにそろえて1本で録り続けるかを選べます。そろえた時も、録画バーと録画一覧で元の配信の画質（「288p→720p」など）が分かります。
・容量の上限
　保存する容量の上限（1〜100 GB）を設定できます。上限を超えたら、古い録画から自動で削除します。

■ 使い方
1. ニコニコ生放送の番組を開くと、プレイヤーの下に録画バーが出て、録画が始まります。
2. 「プレイバック」で少し前を見返せます。録った番組は「録画一覧」（またはツールバーのこの拡張機能のアイコン）で見返せます。
3. 録画する種類・オートスタート・容量の上限などは、録画バーの設定（歯車）から変えられます。

■ ご注意
・録画は、この拡張機能の保存領域（お使いのPCの中）に保存されます。外部に送信することはありません。
・拡張機能をアンインストールすると、録画も削除されます。残したい録画は、先に録画一覧から保存してください。
・リアルタイムに録画するため、PCに負荷がかかります。録画する種類（特にコメントあり・画面録画）が多いほど負荷が上がります。
・録画した番組は、個人で楽しむ範囲でご利用ください。
・この拡張機能は非公式のツールで、株式会社ドワンゴ・ニコニコとは関係ありません。

■ 以前のバージョン（1.2.2 まで）をお使いの方へ
・以前のバージョンで録画したデータは、自動では移しません。録画一覧を開くと「以前のバージョンの録画が ○本あります」と出るので、「取り込む…」から取り込めます。
・更新した時に開いていたニコ生のタブは、開き直すまで以前のバージョンのまま動きます。
・ページの中の録画リストと「分割間隔」の設定はなくなり、録画一覧に置き換わりました。

■ 更新履歴
2.0.0　録画を拡張機能側に数秒ごとに保存。「プレイバック」「録画一覧」、種類ごとの同時録画（コメントなし・コメントあり・画面録画）、配信の画質が変わった時の録り方の設定を追加。録画バーを刷新。以前のバージョンの録画は録画一覧から取り込む。
1.2.2　録画の安定性向上と複数のバグ修正、mp4で録画できない環境ではwebmで録画
```

## プライバシーへの取り組み

「プライバシーへの取り組み」タブに入力します。

### 単一用途の説明

```
ニコニコ生放送で視聴中の番組を録画し、録画した番組を見返したり保存したりするための拡張機能です。
```

### 権限が必要な理由

storage

```
設定（録画する種類・オートスタート・容量の上限など）を保存するために使います。
```

unlimitedStorage

```
録画した動画を、この拡張機能の保存領域（IndexedDB）に保存するために使います。動画は大きいため、ブラウザの通常の容量制限では録画を続けられません。保存する量は、利用者が設定する容量の上限（1〜100 GB）で制限し、上限を超えたら古い録画から削除します。
```

ホストへのアクセス（live.nicovideo.jp のコンテンツスクリプト）

```
ニコニコ生放送の視聴ページに録画バーを表示し、視聴中の番組の映像を録画するために使います。また、以前のバージョンがニコニコ生放送のサイトデータに保存した録画を、利用者の操作で取り込むために使います。
```

リモートコード

```
使用していません（すべてのコードはパッケージに含まれています）。
```

### データの使用

- 収集するユーザーデータ：どれもチェックしません。録画と設定はすべて利用者の PC の中に保存し、外部へ送信しないためです。
- 3つの宣言（第三者への販売・譲渡をしない／単一用途と関係のない目的に使わない／信用力の判断や貸付に使わない）には、すべてチェックします。
- 入力する時は、ストアの最新の定義（「収集」が端末の外への送信を指しているか）を確かめてください。

# ニコ生プレイバックレコーダー
ニコニコ生放送の視聴中の番組を録画し、後で見返すことができるツールです。 

# description

## 概要
視聴中のライブ配信を録画し続け、数秒ごとに自動で保存します。設定した容量に達したら古いものから順に削除されるので、一定期間に視聴した番組の履歴（ログ）が動画で残っていくイメージです。録画を止めずに「さっきのシーン」をその場で見たり（プレイバック）、あとから番組ごとに見返したり、1本の動画にまとめて保存したり（録画一覧）できます。

## 機能

### 録画バー
プレイヤーの下に、1行の録画バーが表示されます。
- 左: 録画の状態（録画中・停止中など）と録画時間
- 中: 録画する種類のボタン（「コメントなし」「コメントあり」の吹き出しのアイコン。そのタブだけ切り替わります。アイコンの左の丸が、今録っている種類は赤く、選んでいて録っていない時は空になります）と、区切って置いた「画面録画」のボタン（押すと始まる）
- 右: 「プレイバック」「録画一覧」、スクリーンショット、設定（画面の中央に開きます）、録画開始・停止
- プレイヤーの操作バーの右端にある丸いボタンで、録画バーを隠す・出すことができます（録画中は赤くなります）。

### 録画する種類
設定で、ページを開いた時に録画する種類を選べます。録画バーのボタンでは、そのタブで録画する種類だけを切り替えられます（他のタブや設定は変わりません。そのタブを閉じるまで、ページを読み直したり他の番組へ移ったりしても続けて使います）。設定で変えた時は、設定を開いたタブにもすぐ使います。選んだ種類は、別々の録画として同時に保存します（種類が多いほどPCの負荷が上がります）。
- コメントなし（初期値）: 映像と音声をそのまま録画します。
- コメントあり: 流れるコメントを重ねて録画します（下の「コメントあり」）。
- 画面録画: ゲームやギフトなどの演出も含めて、プレイヤーの画面をそのまま録画します。設定ではなく、録画バーの「画面録画」を押して始めます（下の「画面録画」）。

録画中に切り替えた場合は、その場で始まる・止まります。「コメントなし」と「コメントあり」は、少なくとも1つは選んだままになります。

### プレイバック
録画バーの「プレイバック」を押すと、録画を止めずに、少し前の映像を別のウィンドウで見られます。生放送を見ながら「さっきのシーン」をその場で確認できます。
- ウィンドウは大きさを変えられ、他のウィンドウの上に重なって表示されます。
- 動画の下は、真ん中に再生の操作、左に種類の切り替え（録画バーと同じ吹き出しのアイコン）と音、右に時間と「ライブ」ボタンが並びます。窓が狭くて入りきらない時は、いらないものから順に隠れます（「10秒」などの文字 → 10秒戻る・進む → 再生ボタン → 番組の経過時間 → 「（5:30前）」 → 「ライブ」の文字 → その場面の時刻）。隠れたボタンの操作は、動画を押す（再生・一時停止）やキーボードでできます。
- 開くとライブの約30秒前から再生します。シークバーで、この番組を録画した範囲のどこへでも移動できます（内部の区切りもつながって再生されます）。シークバーを掴んで動かしている間は、その位置の場面が表示されます（離すと続きから再生）。
- 大きく出る時間は、録画を始めてからの時間です。横に「（番組 30:15:00）」のように番組の経過時間（ニコ生のプレイヤーの表示と同じ）が、その下に「午後5:20時点（5:30前）」のようにその場面の時刻と、ライブからどれだけ前かが出ます。
- プレイバックの音は初めは消えています（ライブの音はそのまま流れます）。「音を出す」ボタンで出せます。
- 動画を押すと、再生・一時停止します。「10秒」ボタンで10秒戻る・進む、「ライブ」ボタンで最新の録画へ戻ります（ライブを見ている間は赤くなります）。最新の録画は数秒ごとに届くので、ライブより少し遅れて追いかけます。
- キーボード: スペースで再生・一時停止、←・→で10秒戻る・進む、Mで音、Lでライブに戻る。
- 「コメントなし」「コメントあり」「画面録画」を同時に録っている場合は、左のアイコンで種類を切り替えられます（見ている種類は、その色になります）。同じ場面から続けて見られます。開いた時と「ライブ」ボタンを押した時は、今録っている種類を表示します。
- 録画を止めた後などに、録り終えた録画を最後まで見ると、少しして止まります（続きが録画されると、続けて再生します）。
- もう一度「プレイバック」を押すか、ウィンドウを閉じると終わります。
- mp4で録画できる環境（最近のChrome）でのみ使えます。

### 録画一覧
録画バーの「録画一覧」（またはChromeのツールバーの拡張機能のアイコン）で、録画を番組ごとに見るページが開きます。録画バーから開くと、見ている番組が選ばれた状態で開きます。
- 左に番組の一覧（画像・録った時間・種類・大きさ）、右に選んだ番組のプレイヤー・タイムライン・録画の一覧が並びます。動画を押すと、再生・一時停止します。プレイヤーの下は、プレイバックと同じく、真ん中に再生の操作、左に種類の切り替えと音、右に時間が並びます。プレイヤーとタイムラインは、スクロールしなくても画面の中に収まります（画面の比率に合わせて動画の大きさが変わります）。
- 番組名・配信者で検索したり、種類で絞り込んだり、大きい順に並べたりできます。「選んで削除…」で、いくつかの番組をまとめて削除できます（容量を空けたい時に）。
- 時間は録画を始めてからの時間で出します。プレイヤーでは、横に番組の経過時間（ニコ生のプレイヤーの表示と同じ）、下に「午後4:27時点」のようにその場面の時刻が出ます（今日でなければ日付も）。タイムラインや録画のファイルにマウスを乗せても、番組の経過時間と時刻が出ます。
- タイムラインには、種類ごとに録った時間が並びます。クリックした時刻から再生し、押したまま動かすと、動かしている間その場面が表示されます。種類の名前を押すと、同じ時刻のまま切り替わります。
- 「保存」で、見ている種類の録画を1本のmp4につないで保存します（画質は変わりません）。▾から、他の種類やすべての種類も保存できます。解像度などの設定が変わった所では、つなぐと再生できなくなるため、ファイルを分けて保存します。
- 右の「録画」の一覧は、保存した時のファイルの単位で並びます。1本ずつ再生・保存・削除できます（録画中の分は削除できません）。番組の録画をまとめて削除するには「…」から選びます。
- 「ニコ生で開く」で、その番組のページを開きます。
- 動画ファイルはmp4形式です（mp4で録画できない環境ではwebm形式になります）。

### 録画の区切り
録画は安定性のため、内部で5分ごとに区切って保存しています。プレイバックと録画一覧ではつながって再生され、まとめて保存すると1本のファイルになります。

### 配信の画質が変わった時
ニコ生の画質（動画の解像度）が番組の途中で変わった時の録り方を、設定で選べます。
- 画質が変わった所で分ける（初期値）: 配信の画質のまま録ります。画質が変わった所で録画が分かれます（保存するファイルも分かれます）。
  - ニコ生は番組を開いた直後の画質が低く、すぐに上がります。録り始めてから10秒以内に画質が変わった時は、それまでの数秒の録画は残さず、変わった後から録ります（数秒だけの低い画質の区間が、別のファイルにならないように）。
- 1本の録画にそろえる: 画質が変わっても、360p（640×360）・450p（800×450）・540p（960×540）・720p（1280×720）・1080p（1920×1080）から選んだ大きさに描き直して、1本の録画として録り続けます。元の画質より大きくすると、引き伸ばされてぼやけます。

### 保存
録画は拡張機能の保存領域に自動で保存されます。録画中も数秒ごとに保存されていくので、ページを閉じたりブラウザが落ちたりしても、それまでの録画は残ります。保存する容量の上限は設定でき、上限を超えたら古い部分から順に削除されます。PCの空き容量が足りない場合も、古いものから順に削除して保存を続けます。あまり大きく設定すると重たくなる場合がありますので、適切に設定してください。

### オートスタート
オートスタートがONになっている場合は、番組の視聴と同時に録画が自動的に始まります。不要な場合はOFFにしてください。

### オートリロード
ライブ映像が止まった時に、映像を再読み込みして録画を再開します。

### スクリーンショット
録画バーのカメラのボタンで、その瞬間のライブ画面を画像で保存します。

### コメントあり
「コメントあり」を選ぶと、画面に流れるコメントを動画に重ねて録画します。
- タブを表示していない時（別のタブを見ている・最小化している）は、コメントは録画されず、映像だけになります。コメントも録りたい時は「画面録画」を使ってください。
- プレイヤーでコメントを非表示にしている間は、コメントは録画されません。
- 運営からのお知らせ（画面上部の固定表示）やニコ生ゲームの画面は録画されません。
- 動画とコメントを合成するため、PCの負荷が上がります。

### 画面録画
録画バーの「画面録画」を押し、Chromeの「このタブを共有」を許可すると、プレイヤーに表示されている画面をそのまま録画します。コメントに加えて、ニコ生ゲームやギフト、運営からのお知らせも録画されます。
- Chromeの決まりで、ページを開くたびに共有の許可が必要です。そのため設定には画面録画のスイッチはなく、録画したい時にその都度、録画バーの「画面録画」を押して始めます。
- 「コメントなし」「コメントあり」の録画と並行して、別の録画として保存します。停止中に押した場合は、選んでいる種類の録画も一緒に始まります。
- 録画していない時はボタンが灰色で、録画中はオレンジの「画面録画中」になり、画面のアイコンの中の丸が赤く点滅します。もう一度押すか、Chromeの「共有を停止」を押すと、画面録画だけが終わります（他の種類の録画は続きます）。
- タブを表示していない時（別のタブを見ている・最小化している）も、コメントやゲームが動いたまま録画されます。
- オートスタートでは、画面録画は始まりません（録画バーの「画面録画」を押すと加わります）。
- 録画の解像度は動画と同じ（720pより低い場合は720p。「1本の録画にそろえる」の場合はその大きさ）ですが、画面に表示されている大きさで取り込むため、プレイヤーを小さく表示していると粗くなります。
- プレイヤーに重なって表示されたもの（この拡張の設定など）も録画されます。

## 補足
- このツールはリアルタイムに録画したり大きな動画データを扱う性質上、場合によってはPCに負荷がかかる場合があります。お使いの環境に合わせた設定でお楽しみください。
- 複数のタブやウィンドウによる並行録画にも対応していますが、負荷が大きくなりますので必ずしも安定して動作するとは限りません。同じ番組を2つのタブで録った場合、録画一覧ではそれぞれ別の録画（ファイル）になります。
- 別ツールの「別窓くん」で開いた番組もオートスタートがONの場合は自動的に録画が開始されます。録画したくない場合はオートスタートをOFFにしてください。
- 録画データは拡張機能の保存領域に保存されます。そのため、次の点にご注意ください。
  - 拡張機能をアンインストールすると、録画データも削除されます。残したい録画は先に録画一覧から保存してください。
  - ブラウザで nicovideo.jp の Cookie やサイトデータを削除しても、録画データは削除されません。
- 以前のバージョン（1.2.2 まで）で録画したデータは、ニコニコ生放送のサイトデータに保存されています。自動では移さず、録画一覧から取り込みます。
  - 更新後にニコ生のページを開くと、録画一覧の番組の一覧の上に「以前のバージョンの録画が ○本あります」と出ます。「取り込む…」を押すと、今の使用量と容量の上限を比べて確かめられます。
  - 取り込んだ録画も容量の上限の対象です。上限を超える分は古い録画（以前の録画）から削除されるので、先に容量の上限を上げてから取り込んでください（確認の画面から上げられます）。
  - 取り込むために、ニコ生のページを裏で開きます（取り込み終えたら閉じます）。取り込んでいる間は、番組の一覧の上に進み具合が出ます。途中でやめても、取り込んだ分はそのまま残り、もう一度取り込むと続きから取り込みます。
  - 取り込んだ録画は、ニコニコ生放送のサイトデータからは消えます。
- 録画中に拡張機能が更新された場合、その後の録画は一時的にニコニコ生放送のサイトデータに保存され、次に視聴ページを開いた時に拡張機能の保存領域へ移されます。一時的に保存するのは保存する容量の上限までで、超えると録画が止まります（ページを開き直すと、拡張機能の保存領域への録画に戻ります）。設定・録画一覧は、ページを開き直すまで使えません（録画バーにお知らせが出ます）。
- 空き容量が足りず、古い録画を削除しても保存できない場合は録画が止まり、録画バーが赤くなって「保存エラー」と表示されます。

# ニコ生プレイバックレコーダー
ニコニコ生放送の視聴中の番組を録画し、後で見返すことができるツールです。 

# description

## 概要
ライブ配信をキャプチャし録画します。録画した動画は設定した分数で分割されストレージに自動保存されていきます。設定した容量に達した場合は古いものから順に削除されます。つまり、一定期間中に視聴した番組の履歴（ログ）が動画で記録されるというイメージです。保存された動画はその場で再生可能なので、「さっきのシーンもう一度見たい」というような場合に役に立ちます。動画はダウンロードも可能です。

## 機能

### 分割録画
録画はメモリや安定性を重視し一定間隔で分割保存されるようになっています。分割間隔は1-60分の間で設定可能です。

### ストレージ保存
録画データは拡張機能の保存領域に自動的に保存されます。録画中も数秒ごとに保存されていくので、ページを閉じたりブラウザが落ちたりしても、それまでの録画は残ります。ストレージとして利用する容量は設定でき、設定値を超えた場合は古い部分から順に削除されます。PCの空き容量が足りない場合も、古いものから順に削除して保存を続けます。あまり大きく設定すると重たくなる場合がありますので、適切に設定してください。

### オートスタート
オートスタートがONになっている場合は番組の視聴と同時に録画が自動的に開始されます。不要な場合はOFFにしてください。

### オートリロード
ライブ映像が止まった時に、映像を再読み込みして録画を再開します。録画はここで分割されます。

### 再生
録画された動画はサムネイルアイコンと共にリストされます。見たい動画のアイコンをクリックすると小窓上ですぐに再生することができます。

### ダウンロード
保存された録画データは分割動画サムネイル上の「DL」ボタンから簡単にダウンロードできます。動画ファイルはmp4形式となっています（mp4で録画できない環境ではwebm形式になります）。（まれに音ズレや映像の乱れがある場合があります）

### スクリーンショット
ライブ画面を画像で保存したい場合はコントロールパネル内のカメラマークをクリックする事でその瞬間のスクリーンショットが直接ダウンロードされます。

### コメント付き録画
設定画面の「コメントを含めて録画」をONにすると、画面に流れるコメントを動画に重ねて録画します。録画中に切り替えた場合は、その時点で録画が分割されて反映されます。
- コメントが重なるのはタブを表示している間だけです。別のタブを見ている間や最小化している間は、動画だけが録画されます。
- プレイヤーでコメントを非表示にしている間は、コメントは録画されません。
- 運営からのお知らせ（画面上部の固定表示）やニコ生ゲームの画面は録画されません。
- 動画とコメントを合成するため、PCの負荷が上がります。

### 画面ごと録画
コントロールパネルの「画面録画」ボタンを押し、Chromeの「このタブを共有」を許可すると、プレイヤーに表示されている画面をそのまま録画します。コメントに加えて、ニコ生ゲームやギフト、運営からのお知らせも録画されます。
- 録画中に押した場合は、その時点で録画が分割されて切り替わります。停止中に押した場合は録画が始まります。
- もう一度ボタンを押すか、Chromeの「共有を停止」を押すと、通常の録画（コメント付き録画の設定に従う）に戻って録画を続けます。
- 別のタブを見ている間や最小化している間も、コメントやゲームが動いたまま録画されます。
- 毎回ボタンと共有の許可が必要なため、オートスタートでは使えません。ページを開き直すと通常の録画に戻ります。
- 録画の解像度は動画と同じですが、画面に表示されている大きさで取り込むため、プレイヤーを小さく表示していると粗くなります。
- プレイヤーに重なって表示されたもの（この拡張の再生用の小窓や設定画面など）も録画されます。

## 補足
- このツールはリアルタイムに録画したり大きな動画データを扱う性質上、場合によってはPCに負荷がかかる場合があります。お使いの環境に合わせた設定でお楽しみください。
- 複数のタブやウィンドウによる並行録画にも対応していますが、負荷が大きくなりますので必ずしも安定して動作するとは限りません。
- 別ツールの「別窓くん」で開いた番組もオートスタートがONの場合は自動的に録画が開始されます。録画したくない場合はオートスタートをOFFにしてください。
- 録画データは拡張機能の保存領域に保存されます。そのため、次の点にご注意ください。
  - 拡張機能をアンインストールすると、録画データも削除されます。残したい録画は先にダウンロードしてください。
  - ブラウザで nicovideo.jp の Cookie やサイトデータを削除しても、録画データは削除されません。
- 以前のバージョン（1.2.2 まで）で録画したデータは、ニコニコ生放送のサイトデータに保存されています。更新後に初めて視聴ページを開いた時に、拡張機能の保存領域へ自動的に移されます。
- 録画中に拡張機能が更新された場合、その後の録画は一時的にニコニコ生放送のサイトデータに保存され、次に視聴ページを開いた時に拡張機能の保存領域へ移されます。
- ストレージの空きが足りず、古い録画を削除しても保存できない場合は録画が停止し、「保存エラー」と表示されます。
